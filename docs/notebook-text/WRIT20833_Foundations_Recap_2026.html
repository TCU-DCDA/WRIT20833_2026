The Posts

Here is a short online discussion. A university library plans to turn one of its quiet floors into a collaborative floor where talking is allowed, and people respond: six new posts and two replies. The discussion is invented, written for this notebook from the points of view of different library users: a commuter, a student-athlete, the overnight desk staff, and others. Each post is a dictionary with three fields: code (a short label, "P1" to "P8"), text, and replyto (the code of the post it answers, or "" for a new post). The whole collection is a list of those dictionaries, the same shape as Wednesday's artists archive, just with longer text.

Anyone who later loads this data can't tell which fields came from the post and which came from a reader. When you add a field, you're writing an interpretation into the data.

3. Filter the Records

Filtering is the same pattern you've used all week: start an empty list, loop, test each item with an if, and .append() the ones that pass. Here we keep only the replies. One small new piece: "" is an empty string, quotes with nothing between them. A new post has "" in its replyto field, so post["replyto"] != "" (!= means "not equal") is True only for a reply.

replies = []
for post in POSTS:
    if post["reply_to"] != "":
        replies.append(post)

for post in replies:
    print(post["code"], "replied to", post["reply_to"])

4. Write a Small Function

You just wrote a keyword test inside a loop. Wrapping it in a function gives it a name, mentions, so you can reuse it with any post and any word, as you did with islong on Wednesday. - It takes two parameters: the post to check, and the word to look for - Its return line hands back a comparison, so the answer is True or False, like isrecent on Wednesday

def mentions(post, word):
    # True if the post's text contains `word`, in any capitalization
    return word.lower() in post["text"].lower()

print(mentions(POSTS[0], "quiet"))   # P1
print(mentions(POSTS[3], "quiet"))   # P4

if / elif / else

An if statement runs code only when a condition is True. Add elif (else if) for additional checks, and else as a catch-all. The structure: python if condition: do this elif anothercondition: do this instead else: do this if nothing above was True - Each condition line ends with a colon :, and the code underneath is indented - Python checks from the top and runs only the first block whose condition is True - elif and else are optional; you can have as many elifs as you need

tcu_score = 34
smu_score = 31

if tcu_score > smu_score:
    print("TCU wins!")
elif tcu_score == smu_score:
    print("Headed to overtime")
else:
    print("Better luck next year")

Two conditions can be joined with and (both must be true) or or (either one will do). The structure: python if condition1 and condition2: # True only if both are True if condition1 or condition2: # True if either one is True if not condition: # not flips it: True becomes False, False becomes True A condition is just a True/False value, so you can also store it in a variable and use the name later: python isadult = age >= 18 # isadult now holds True or False if isadult and not isbanned: ...

List Methods

Methods are actions you can perform on a list. They use dot notation: list.method() One big difference from string methods: string methods hand back a new string and leave the original alone. Most list methods change the list itself and hand back nothing. So write artists.sort() on its own line, not artists = artists.sort(), which would replace your list with None (Python's word for "nothing").

For Loops

A for loop repeats an action for every item in a list. This is where coding gets powerful — instead of writing the same code over and over, you write it once and the loop handles the rest. The structure: python for item in mylist: do something with item - item is a temporary variable that takes on each value in the list, one at a time - The indented code runs once per item - You can name item whatever makes sense (name, tag, year, etc.)

# loop through our platforms list

Counting with loops

A common pattern: start a counter at 0, then add to it inside a loop. The structure: python count = 0 for item in mylist: if condition about item: count = count + 1 - The counter starts before the loop. Inside the loop it would reset to 0 on every item - count = count + 1 means "take the current count, add one, store it back"

# count how many hashtags mention TCU
tags = ["#TCU", "#GoFrogs", "#FortWorth", "#TCU", "#BigXII", "#TCU"]

tcu_count = 0

for tag in tags:
    if tag == "#TCU":
        tcu_count = tcu_count + 1

print(f"TCU was mentioned {tcu_count} times out of {len(tags)} total tags")

Building new lists from old ones

The structure: python newlist = [] for item in mylist: if condition about item: newlist.append(item) - The empty list starts before the loop, like a counter - To keep the items that don't match, test with not in: "#" not in tag is True for a tag with no #

Using enumerate() — tracking position

Sometimes you need to know both the item and its position. enumerate() gives you both. The structure: python for position, item in enumerate(mylist, 1): do something with position and item - enumerate() hands the loop a pair each time: a position number and an item - So the loop gets two variables, separated by a comma: the position first, then the item - The 1 says to start counting at 1. Leave it out and counting starts at 0

# create a numbered playlist
playlist = ["Not Like Us", "Espresso", "Birds of a Feather", "APT.", "Die With a Smile"]

for position, song in enumerate(playlist, 1):  # start counting at 1
    print(f"{position}. {song}")

A loop inside a loop

Sometimes each item has to be checked against a whole list of things: does this caption mention any of several words? That takes a loop inside a loop. The structure: python newlist = [] for item in mylist: found = False for thing in otherlist: if thing in item: found = True if found: newlist.append(item) - The inner loop runs all the way through for each item of the outer loop - found is a True/False switch. It starts at False for every item and flips to True on any match - The .append() sits in the outer loop, after the inner loop has finished. Put it inside the inner loop and an item that matches two things gets added twice - Indentation tells Python which loop each line belongs to, so line it up carefully

# which captions mention ANY of these words?
team_words = ["frogs", "tcu", "purple"]
captions = ["Game day!", "Purple everywhere", "Go Frogs, go TCU", "Studying all weekend"]

matches = []
for caption in captions:
    found = False                  # no match yet for this caption
    for word in team_words:
        if word in caption.lower():
            found = True           # at least one word matched
    if found:                      # back in the outer loop: add the caption once
        matches.append(caption)

print(matches)

Putting It All Together

Let's combine everything — lists, methods, loops, and conditionals — to do something that actually looks like digital humanities work.

# analyze hashtag frequency from a mock social media dataset
social_tags = ["#climate", "#action", "#justice", "#climate", "#equality",
               "#justice", "#climate", "#activism", "#equality", "#climate"]

# find unique tags and count each one
analyzed = []

print("Hashtag Frequency Analysis")
print("-" * 30)   # * repeats a string: a line of 30 dashes

for tag in social_tags:
    if tag not in analyzed:
        count = social_tags.count(tag)
        print(f"{tag}: {count} times")
        analyzed.append(tag)

print(f"\nTotal tags: {len(social_tags)}")
print(f"Unique tags: {len(analyzed)}")

# shortcut: set() keeps one copy of each item, so len(set(...)) counts the unique ones
print(f"Unique tags, using set(): {len(set(social_tags))}")

def classify_year(year):
    if year <= 1964:
        return "Boomer"
    elif year <= 1980:
        return "Gen X"
    elif year <= 1996:
        return "Millennial"
    else:
        return "Gen Z"

# now we can use it in a loop
family = [1962, 1985, 1997, 2004]

for year in family:
    generation = classify_year(year)
    print(f"{year} → {generation}")

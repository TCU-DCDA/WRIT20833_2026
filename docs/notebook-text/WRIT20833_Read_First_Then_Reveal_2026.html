Why we're doing this

- From the lecture: close reading and distant reading answer different questions. VADER reads every comment at once and hands back a number. You read a few comments slowly and judge what the writer means. This notebook puts the two side by side. - Where you'll use it: HW3 B3. This notebook runs B3's two cells, line for line, on real comments, so the steps are familiar before you do them on your own data. - The question to keep asking: what did VADER's number flatten, and could you have read the writer's side off their tone? The order matters. If you see VADER's score first, it nudges your reading ("+0.99, so it must be friendly"). So we read first and label, then reveal the scores.

Setup

The same tools as the Sentiment with VADER notebook, with the same names HW3 uses: getsentiment turns a comment into its compound score, and labelsentiment turns a score into "positive", "negative", or "neutral".

# PLUMBING: the tools from the VADER notebook (Parts 2 and 4)
import pandas as pd
from vaderSentiment.vaderSentiment import SentimentIntensityAnalyzer

analyzer = SentimentIntensityAnalyzer()

def get_sentiment(text):
    return analyzer.polarity_scores(text)["compound"]

def label_sentiment(score):
    if score >= 0.05:
        return "positive"
    elif score <= -0.05:
        return "negative"
    return "neutral"

print("VADER ready.")

Step 1: Read the Extremes, with the Scores Hidden

This is HW3's B3 part 1, line for line. It picks the 5 comments VADER scored highest and the 5 it scored lowest, then prints only their text, in row order, so you can't tell which group a comment came from. Some are long. That's a pattern worth noticing: the highest and lowest scores often go to the longest comments, because a long comment piles up more scored words.

What B3 part 1 does, step by step. The numbers match the # 1 to # 6 tags in the code cell. 1. min(5, len(df) // 2): 5 comments from each end, or half your rows if you have fewer than 10, so both groups are the same size. (// divides and drops the remainder: 7 // 2 is 3.) 2. .nlargest(howmany, "sentiment"): keeps the rows with the highest scores. 3. .drop(highest.index): sets those rows aside first, so .nsmallest can't pick any of them again. Without it, a small or one-sided dataset could put the same comment in both groups. 4. .assign(group=...) adds a column saying which group each row came from; pd.concat([...]) stacks the two small tables into one. 5. .sortindex() puts the rows in row-number order, which mixes the two groups together; .iterrows() hands you the table one row at a time, as a pair: the row's number and the row itself. 6. textwrap.fill(...) breaks a long comment into lines of at most 90 characters, indented 4 spaces, so you can read it without scrolling sideways. (import textwrap at the top loads that tool; it comes with Python.)

# B3 — part 1: read the extremes (scores hidden). Steps 1-6 are explained in the text above.
# Run this cell, then read the comments it prints.
import textwrap
how_many = min(5, len(df) // 2)                                     # 1
highest = df.nlargest(how_many, "sentiment")                        # 2
lowest = df.drop(highest.index).nsmallest(how_many, "sentiment")    # 3
extremes = pd.concat([highest.assign(group="highest"),
                      lowest.assign(group="lowest")])               # 4
print(len(highest), "highest-scoring and", len(lowest), "lowest-scoring comments, in row order:")
print()
for row_number, row in extremes.sort_index().iterrows():            # 5
    print(f"[{row_number}]")
    print(textwrap.fill(row[text_column], width=90,
                        initial_indent="    ", subsequent_indent="    "))   # 6
    print()

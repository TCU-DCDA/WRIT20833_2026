Dictionaries

Last time, lists stored items in order. But a lot of cultural data isn't just a sequence — it's labeled. A song has a title, an artist, a year. A dictionary stores key–value pairs: each value gets a name (its key) that you look it up by. - Created with curly braces {} - Each entry is key: value, entries separated by commas - Look a value up by its key with dictionary["key"]

album = {
    "title": "Renaissance",
    "artist": "Beyoncé",
    "year": 2022,
    "tracks": 16
}

print(album["title"])
print(album["artist"], "—", album["year"])

Counting with a Dictionary

Functions

A function packages code into a reusable tool. You define it once with def, give it inputs (parameters), and it can hand back a result with return. python def functionname(input): do something return result

def greet(name):
    return f"Welcome, {name}!"

print(greet("Frog fan"))
print(greet("Dr. Rode"))

Why functions? Write the recipe once.

Without a function you'd copy-paste the same lines every time you needed them. With one, you write the logic once and reuse it — and if you fix it, you fix it everywhere at once.

def classify_year(year):
    if year <= 1964:
        return "Boomer"
    elif year <= 1980:
        return "Gen X"
    elif year <= 1996:
        return "Millennial"
    else:
        return "Gen Z"

print(classify_year(1990))
print(classify_year(2005))

Putting It All Together

Now combine functions and dictionaries into one reusable tool: a function that takes a list of words and returns a dictionary of how often each appears. This is a first draft of the term-frequency counter you'll use on real data next week.

def count_words(word_list):
    counts = {}
    for word in word_list:
        if word in counts:
            counts[word] = counts[word] + 1
        else:
            counts[word] = 1
    return counts

sample = ["god", "law", "freedom", "god", "school", "god", "law"]
print(count_words(sample))

Sneak Preview: Where This Is Going

Next week we leave practice data behind for real text — 93 actual YouTube comments about a Texas law. Your countwords function is the seed of term frequency: finding what a text is really about by counting its words. Python even ships with a tool, Counter, that does what you just wrote:

from collections import Counter

comment = "god god law freedom god school law god"
words = comment.split()

print(Counter(words).most_common(3))   # the 3 most frequent words

That little count is already a tiny act of interpretation: we chose to split on spaces, we decided every word counts equally. Next week we'll ask what choices like these reveal — and what they flatten.

Why we're doing this

Optional, on your own. Nothing in this course requires it, and we won't go through it in class. Everything you need for the homework, you can do with the loops you already know. - What it is. A list comprehension is a loop that builds a list, written on one line. It's a shortcut for the loop-and-.append() pattern from Days 3–4. It does nothing new; it's just more compact. - Why bother. You'll see them: in some of our starter code, in the Topic Modeling notebook, and in code that AI tools write. This notebook lets you learn to read one by turning it back into a loop, and gives you practice writing a few. - A fair warning. Compact isn't the same as clear. For many people, the loop is easier to read, to debug, and to explain. It is always fine to write the loop. Use a comprehension only when it feels clearer to you. Each exercise ends with a Check: line, the output you should see, so you can work on your own.

Step 1 — The loop you already know

Say we want the number of words in each comment. Here is the Day 3–4 way: start with an empty list, loop, and .append() one result per item.

word_counts = []
for c in comments:
    word_counts.append(len(c.split()))

print(word_counts)

Check: [7, 8, 7, 6, 6, 4, 8, 12] Now the same list, built in one line:

word_counts_short = [len(c.split()) for c in comments]

print(word_counts_short)
print(word_counts == word_counts_short)

Same list, and the last line prints True. Put the two side by side and the pieces line up: wordcounts = [] wordcountsshort = [ len(c.split()) for c in comments ] for c in comments: ^ WHAT to keep ^ the loop line wordcounts.append( len(c.split()) ) The pattern: [ WHAT-TO-KEEP for ITEM in LIST ] Read it out loud as a sentence: "make a list of len(c.split()), for each c in comments."

Step 3 — Adding a filter

The loops you wrote in Term Frequency had an if inside: keep only the items that pass a test. A comprehension can do that too. Here is the loop version first: keep only the comments that mention religion.

about_religion = []
for c in comments:
    if "religion" in c.lower():
        about_religion.append(c)

print(len(about_religion), "comments")
for c in about_religion:
    print("-", c)

Check: 3 comments, then the three comments that contain religion. In a comprehension, the if moves to the end: The pattern: [ WHAT-TO-KEEP for ITEM in LIST if TEST ]

# type along: the same list in one line, saved as `about_religion_short`
#             then print whether it equals `about_religion`

Check: True Notice the order: the keep part comes first, the test comes last. In the loop, the test came first. That flip is the part that trips people up.

Step 4 — Predict first: read one

Don't run this yet. Read the comprehension, and write your guess in the comment: what list will it print? (Hint: turn it into the loop in your head. Which words does it keep?)

# my guess:

words = "the cat and the hat".split()
kept = [w for w in words if w != "the"]
print(kept)

Run it. Check: ['cat', 'and', 'hat'] The loop it stands for: kept = [], then for w in words:, then if w != "the":, then kept.append(w). Words that fail the test are skipped, so both thes disappear.

What to take away

- A list comprehension is a loop that builds a list, on one line: [ WHAT-TO-KEEP for ITEM in LIST if TEST ] (the if TEST part is optional). - To read one, turn it into a loop: empty list, for, if, .append(). - To write one, you can always write the loop first. - Neither form is "the right one." Choose the version you can explain to someone else. When you meet a [ ... for ... in ... ] in the Topic Modeling notebook, in homework starter code, or in something an AI wrote, you now know how to read it.

A note: you didn't build VADER — and that's normal

VADER is a sentiment lexicon: thousands of words hand-scored for feeling, plus rules for "!", ALL CAPS, and negation, compiled and tuned by researchers. Almost nobody writes one from scratch — you pip install it. (Long before AI, you'd still have reached for a library like this; today you might ask an AI to help use it.) Borrowing it is expected, not cheating. But A4 showed the catch: a borrowed tool carries someone else's assumptions and can be confidently wrong (sarcasm, jokes, and quoting the other side all fool it). So the real skill isn't building VADER — it's judging whether to trust it on your text. That's exactly what the human-vs-VADER check in B3 is for. What B3 part 1 does, step by step. The numbers match the # 1 to # 6 tags in the code cell. 1. min(5, len(df) // 2): 5 comments from each end, or half your rows if you have fewer than 10, so both groups are the same size. (// divides and drops the remainder: 7 // 2 is 3.) 2. .nlargest(howmany, "sentiment"): keeps the rows with the highest scores. 3. .drop(highest.index): sets those rows aside first, so .nsmallest can't pick any of them again. Without it, a small or one-sided dataset could put the same comment in both groups. 4. .assign(group=...) adds a column saying which group each row came from; pd.concat([...]) stacks the two small tables into one. 5. .sortindex() puts the rows in row-number order, which mixes the two groups together; .iterrows() hands you the table one row at a time, as a pair: the row's number and the row itself. 6. textwrap.fill(...) breaks a long comment into lines of at most 90 characters, indented 4 spaces, so you can read it without scrolling sideways. (import textwrap at the top loads that tool; it comes with Python.)

# B3 — part 1: read the extremes (scores hidden). Steps 1-6 are explained in the text above.

how_many = min(5, len(df) // 2)                                     # 1
highest = df.nlargest(how_many, "sentiment")                        # 2
lowest = df.drop(highest.index).nsmallest(how_many, "sentiment")    # 3
extremes = pd.concat([highest.assign(group="highest"),
                      lowest.assign(group="lowest")])               # 4
print(len(highest), "highest-scoring and", len(lowest), "lowest-scoring comments, in row order:")
print()

How part 2 works. You type your labels into a dictionary, and pandas attaches them to the table. The structure: python mystance = { rownumber: "support", anotherrownumber: "oppose", } extremes["stance"] = extremes.index.map(mystance) - Each key is a row number from part 1's printout (the number in square brackets), typed without quotes. Each value is your label, in quotes. - extremes.index is the table's row numbers. .map(mystance) looks each one up in your dictionary and gives back your label, like mystance[rownumber] done for every row at once. - A row you haven't labeled yet shows NaN (pandas' mark for an empty cell), so you can see which ones are left. - The two filled-in entries (0 and 1) only show the pattern. # C1
def top_words(comments, how_many=8):   # how_many=8: if you don't say how many, you get 8
    words = []
    for comment in comments:
        for word in split_into_words(comment):
            if word and word not in stopwords:   # skip empty strings and stopwords, as in HW2
                words.append(word)
    return Counter(words).most_common(how_many)

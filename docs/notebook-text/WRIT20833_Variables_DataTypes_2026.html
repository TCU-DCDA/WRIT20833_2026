Variables

A variable is a label we apply to a stored data point. - The data exists at a specific memory location with its own address - The variable is just a human-friendly name that points to that location - The data and the variable name are separate things The structure: python variablename = value # store a value under a name print(variablename) # show the value - = means store, not "is equal to." (Python asks whether two things are equal with ==, later today.) - The name goes on the left, the value on the right - print() displays whatever you put inside its parentheses - Anything after a # is a comment. Python skips it; it's a note for people reading the code. This course asks you to write comments that explain your choices

Variable Names

Good variable names

- Descriptive: songtitle is better than x - snakecase: words separated by underscores (commentcount, not commentCount) - Lowercase: capital letters are reserved for special things in Python

Off-limits names

Python has reserved words you can't use as variable names. If you accidentally use one, things break quietly: - type, print, list, str, int — these are built-in functions - for, if, while, class, return — these are language keywords You'll use this. A name is the first claim your code makes about its data. Suppose you have comments that a tool scored below zero. Call them angrycomments and you've asserted something the tool never measured; negativescores says only what you know. You'll make exactly this call in HW3, when sentiment scores become labels.

Type Errors

Back to the core. If we skipped the last two sections, start again here. Python will not quietly guess what you meant when you mix types. It stops and tells you.

# What happens when you mix types?

greeting = "hello"
number = 5

# this will cause a TypeError — read the error message carefully
greeting + number

Read the last line of that message. It names the two types that didn't fit together. There are two ways to fix it, depending on what you want: python str(40) # "40": turns a value into a string f"Score: {points}" # an f-string drops a value into text, whatever its type - With str(), the number becomes text, so + can glue it to another string - An f-string (an f before the opening quote, the variable inside {}) does the conversion for you. Sneak Preview: Where This Is Going

Everything we just learned — variables, strings, .split(), f-strings — is the foundation for analyzing real cultural data. Here's a taste of what we'll be doing in a few weeks.

# A real headline about the Ten Commandments in public schools
headline = "Louisiana law requiring Ten Commandments in classrooms blocked by federal judge"

# Use .split() to count words
word_count = len(headline.split())

# Use `in` to check for a keyword
mentions_law = "law" in headline

# Use an f-string to report what we found
print(f"Headline: {headline}")
print(f"Word count: {word_count}")
print(f"Mentions 'law': {mentions_law}")

Variables

A variable is a label we apply to a stored data point. - The data exists at a specific memory location with its own address - The variable is just a human-friendly name that points to that location - The data and the variable name are separate things

Variable Names

Good variable names

- Descriptive: songtitle is better than x - snakecase: words separated by underscores (commentcount, not commentCount) - Lowercase: capital letters are reserved for special things in Python

Off-limits names

Python has reserved words you can't use as variable names. If you accidentally use one, things break quietly: - type, print, list, str, int — these are built-in functions - for, if, while, class, return — these are language keywords

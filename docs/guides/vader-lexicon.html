VADER Lexicon Explorer

Every word, emoticon, and emoji VADER knows, and the numbers it gives them.

The two data files bundled with VADER (version 3.3.2), side by side. Words and emoticons come with human ratings. The emoji file holds only short English descriptions, not ratings: VADER swaps each emoji it recognizes for its description and scores whatever words in it are on the word list.

These lists are only part of how VADER scores a sentence. Rules for “not,” “very,” ALL CAPS, “!!!” and “but” can change a score, using words that aren't on either list.

Each score is the rating stored in vader_lexicon.txt, on a scale from −4 (extremely negative) to +4 (extremely positive). It is meant to be the mean of the 10 human ratings listed beside it, and it is for every entry but one, which is marked. The small chart shows how those 10 people voted, one bar per point on the scale. A wide spread means the raters disagreed. An average sums up what those ten people judged for one study; it doesn't settle what a word means in every community or context. These are stored ratings, not the −1 to +1 compound scores on the Emoji tab, so the numbers on the two tabs can't be compared directly.

Being listed doesn't guarantee being used. VADER lowercases text before it looks anything up, so the 14 entries with capital letters (like :P) are never used. Each is marked with what VADER looks up instead.

The score here is VADER's compound score (−1 to +1) for the emoji typed on its own, the same number the class notebook uses. It is calculated from the highlighted words in the emoji's description, which comes from emoji_utf8_lexicon.txt. It is not a stored rating, so it can't be compared directly with the −4 to +4 numbers on the other tab, and the same emoji can score differently inside a sentence. Positive means ≥ 0.05 and negative means ≤ −0.05, the same cutoffs as label_sentiment() in the notebook.

The number beside each highlighted word is the value VADER used in that description. It is usually the word's rating from the other tab, but a rule can change it: a word in ALL CAPS counts for more when the rest of the text isn't in caps, “slightly” makes the next word count for less, and in “sad but relieved face” the word after “but” counts for more and the word before it for less.

A score of 0 does not mean the emoji is neutral. For the emoji on this page it means VADER found no word it could score in what the emoji became. Usually that's because no word in the description is on the word list. 👍 and 💀 both score 0. Sometimes a known word is there but hidden: an invisible character attached to “heart” keeps ❤️ at 0 (see the notes at the bottom). In a longer sentence, positive and negative words can also cancel out to 0.

An emoticon and an emoji can mean the same thing and still get very different scores. Both columns here are the same kind of number, VADER's compound score (−1 to +1) for the symbol typed on its own, so they can be compared directly. What differs is where the number comes from.

Emoticons were rated by people. Ten raters scored :) itself, and VADER converts their average into the compound score. VADER's emoji file contains descriptions, not ratings. VADER swaps each emoji it recognizes for the English description stored in that file, then scores the words in the description. The description is a layer of interpretation someone wrote, and the score can only be as good as that wording.

So 💔 counts as positive: “heart” (+3.2) outweighs “broken” (−2.1). VADER can't tell that the phrase means heartbreak. Typing the words “broken heart” scores the same +0.27. And 😡 counts as 0, because VADER's description for it is “pouting face” and neither word is on the list.

A gap between the two columns shows two VADER numbers disagreeing. It doesn't tell you which symbol people actually feel more strongly about. The pairs are our choice of rough equivalents, not part of VADER. Try others: search the Words tab for an emoticon and the Emoji tab for its match.

About the data

Both files come from vaderSentiment 3.3.2, the version the course notebooks install (pip install vaderSentiment==3.3.2). The emoji scores were produced by running VADER's own polarity_scores() on each emoji. The word list's ratings were collected by Hutto and Gilbert for their 2014 ICWSM paper.

Listed twice. 14 tokens appear twice in the word file with different ratings (for example lol and ok). VADER keeps the second entry. The first is marked “not used.”

Stored rating that doesn't match its ratings. lmfao is stored as 2.5, but its 10 listed ratings average 2.4. VADER uses the stored number. It is marked in the list.

VADER swaps emoji one character at a time. Before it scores anything, VADER walks through the text one character (one Unicode code point) at a time and replaces each character it finds in its emoji file. Emoji built from several characters (skin tones, flags, family groups) are never looked up as a whole. Each part it recognizes is replaced on its own, so “👍🏽” reaches VADER as “thumbs up medium skin tone.” Parts it doesn't recognize stay in the text unchanged: 🇺🇸 is listed as “United States”, but VADER never converts it. Invisible joining and style characters stay too, shown here as ZWJ and VS16, and they can break a word VADER would otherwise know. The red heart with the emoji-style character attached (❤️, heart + VS16) scores 0, while the plain ❤ scores +0.64: VADER reads “heart” with VS16 stuck to it, which isn't on the word list. When what VADER reads differs from the description, it is shown under the description.

Unsupported emoji aren't harmlessly skipped. An emoji missing from VADER's file (newer ones, like 🥲) stays in the text. Typed right after a word, it glues onto that word and hides it: “good🥲” scores 0, while “good 🥲” scores +0.440.

Capital letters. VADER lowercases every word before looking it up, so the 14 entries with capital letters are never used directly. Most have a lowercase twin with the same rating, but not all: :-Þ never scores, because :-þ isn't listed; :P is listed at +1.4, but VADER uses :p at +1.0; :Þ never scores, because :þ isn't listed; O.o is listed at −0.6, but VADER uses o.o at −0.8; o.O is listed at −0.6, but VADER uses o.o at −0.8.

Version matters. The counts on this page are for version 3.3.2. Another version may ship different files.
